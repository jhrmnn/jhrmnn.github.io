   thin wrappers (cv-industry.tex.in, cv-industry-portal.tex.in), selects the
   layout — there is one document here, not two.

   tech (portal = false): two-column one-pager for channels where a human opens
   the PDF. Keeps the academic CV's identity (Baskerville faces, grey ramp, left
   band, dot-underlined links) with the band as a content sidebar.

   portal (portal = true): single-column, standard headings, full publication
   list, for blind submissions through applicant-tracking systems. A utility
   artifact: no design effort, only parseability.

   In both, the main column is emitted BEFORE the sidebar so that a parser
   reading the content stream in order meets the name and contact details
   first. The sidebar is an absolutely positioned overlay, so moving it last
   costs nothing visually. #>

<# Contact entries render their own destination as the visible text, so the
   address survives a parser that strips link annotations. Google Scholar is the
   one exception: its URL is a bare user id, useless as visible text. #>
<+ macro contact_line() +>
<+- set parts = [] +>
<+- for key in industry.contact_keys +>
<+- set val = contact[key][0] +>
<+- set pre = contact[key][1] +>
<+- set disp = val if pre.startswith("mailto:") else (pre|replace("https://", "")|replace("www.", "")) ~ val +>
<+- set _ = parts.append("\\href{" ~ pre ~ val ~ "}{" ~ disp ~ "}") +>
<+- endfor +>
<+- set gs = contact["Google Scholar"] +>
<+- set _ = parts.append("\\href{" ~ gs[1] ~ gs[0] ~ "}{Google Scholar}") +>
<< parts|join("~$\\cdot$~") >>
<+- endmacro +>

\vspace{0.15em}
\begin{itemize}\small

<+ endfor +>
\end{itemize}
<+ if not loop.last +>\vspace{0.55em}<+ endif +>
<+ endfor +>
<+ endmacro +>
